# cpr_loan

## สร้างบัญชีผู้ดูแลระบบครั้งแรก

1. สร้างฐานข้อมูล `cpr_loan_db` และรันคำสั่งใน `setup.sql`
2. เปิด `http://localhost/cpr_loan/create_admin.php` แล้วกรอกแบบฟอร์ม
3. เข้า `http://localhost/cpr_loan/` เพื่อเข้าสู่ระบบแอดมิน

แบบฟอร์มสร้างแอดมินใช้ได้เฉพาะเมื่อยังไม่มีบัญชีที่มีสิทธิ์ Admin ในระบบ ส่วนบัญชีที่ไม่ใช่แอดมินจะไม่สามารถเข้าสู่ระบบได้

## อัปเดตทะเบียนหุ่น CPR

หลังอัปเดตโค้ด ให้เลือกฐานข้อมูล `cpr_loan_db` ใน phpMyAdmin แล้วรัน `setup.sql` อีกครั้ง คำสั่งจะเพิ่มตารางทะเบียนหุ่นและรายละเอียดหุ่นที่ยังไม่มี พร้อมรายชื่อเริ่มต้น โดยไม่ลบใบยืมเดิม

รายชื่อเริ่มต้น: Tommy 1, Tommy 2, Tommy 3, Tommy 4, Taylor, Davin, Jacob, Edward, Madison, Angelina, Kimberly, Jasmine, Alexandra, Sarah และ Morgan

แอดมินจัดการเพิ่ม แก้ไข ปิดใช้งาน และเปิดใช้งานหุ่นได้จากเมนู “จัดการหุ่น CPR” หุ่นที่มีประวัติใบยืมจะถูกปิดใช้งานแทนการลบ เพื่อเก็บประวัติไว้

สามารถเพิ่มรายละเอียด เช่น รุ่น สภาพ หรือหมายเหตุของหุ่นแต่ละตัวได้จากแบบฟอร์มจัดการหุ่น CPR

ใบยืมที่สร้างก่อนเพิ่มการระบุชื่อจะยังไม่ทราบชื่อหุ่น ระบบจะกันจำนวนตามใบยืมเดิมไว้จนกว่าจะคืน และแสดงคำเตือนในแบบฟอร์ม
